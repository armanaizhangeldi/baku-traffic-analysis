 Baku Traffic Analysis

A data science project focused on analyzing the relationship between vehicle volume, days of the week, and traffic congestion in Baku city. The project identifies traffic patterns, peak congestion hours, and weekly trends to provide data-driven insights.

 Dataset Information
Data Source: Kaggle
Note on Files: Due to GitHub file size limits, the main dataset is uploaded as a compressed archive: `traffic.csv.zip`. 
Setup: Before running the notebook, please extract `traffic.csv.zip` directly into the project root folder.

Technologies & Libraries Used
Language: Python
Data Manipulation: Pandas, NumPy
Data Visualization: Matplotlib, Seaborn
Environment: Jupyter Notebook (`baku.ipynb`)

 Key Analysis Goals
1. Identify the exact peak hours for traffic congestion in Baku.
2. Compare traffic volume differences between weekdays and weekends.
3. Visualize congestion hotspots and hourly trends using charts.
 How to Run the Project
1. Clone this repository or download the ZIP file.
2. Unzip `traffic.csv.zip` to get the raw `traffic.csv` file.
3. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```
4. Open the Jupyter Notebook terminal and launch the project:
   ```bash
   jupyter notebook baku.ipynb
   ```
